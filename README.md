# Kinly

An AI care companion for older adults, living in WhatsApp.

Kinly checks every pill from a photo, reminds proactively, calls when something's wrong, and keeps family and care managers in the loop.

- Product idea and research: [`idea/IDEA.md`](idea/IDEA.md)
- Pill appearance data: [`med/`](med/) (Taiwan FDA open data, dataset 42)

Built for a YC hackathon.
